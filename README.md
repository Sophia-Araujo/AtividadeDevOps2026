## 📖 Sobre o Repositório

Este espaço reúne todas as entregas práticas e experimentações realizadas em laboratório, focando na aplicação direta de conceitos como criação de pipelines, conteinerização de aplicações, orquestração e testes automatizados.

### 🎯 Objetivos:
- 🧪 Desenvolver soluções práticas para os desafios propostos em aula.
- ⚙️ Criar e validar arquivos de configuração (Dockerfiles, Docker Compose, Manifests K8s, Pipelines YAML).
- 🚀 Manter o histórico de evolução e implementação das atividades práticas.

## ⚡ Como Executar os Labs

- Cada diretório de atividade possui seus próprios scripts e instruções específicas de execução.
- Certifique-se de possuir o ambiente local configurado (Git, Docker, CLI necessária) antes de iniciar os testes.
- Siga as instruções do arquivo correspondente a cada atividade para subir contêineres, aplicar manifestos ou rodar testes locais.
